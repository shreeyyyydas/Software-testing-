# Software-testing-
basic project on built app generating test cases and bug report<br>
I am taking here example of any pre built app let say any Ecommerce app i.e. Amazon.<br>
Testing apps lead to high quality app delivery. These test cases are applied manually side by side opening app to test each test cases one at a time. To see if it actually works as intended.<br>
Status in test cases defines if it os yay or nay.
